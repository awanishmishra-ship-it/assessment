# Toolshop Playwright tests

Automation package for the Toolshop QA assessment.

**Full setup, commands, reports, structure, and troubleshooting:** see the repository root [README.md](../README.md).

From this directory:

```powershell
npm install
npx playwright install chromium
npm test
npm run test:ui
npm run test:api
npm run test:smoke
npm run test:regression
npm run report
```
